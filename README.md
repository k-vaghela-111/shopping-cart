## ✨ Overview
A simple shopping cart web app built with **HTML, CSS, and JavaScript**.  
Users can browse products, add/remove items from the cart, view the total price, and checkout.

---


---

## ⚙️ Features
- 🛍️ Product listing with name & price  
- ➕ Add items to cart  
- ❌ Remove items from cart  
- 💰 Dynamic total price calculation  
- ✅ Checkout clears the cart
